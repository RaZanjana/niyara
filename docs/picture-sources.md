# Where each picture came from

Every picture and film on the site was made in Higgsfield. This list links
each shot ID to its Higgsfield job, so a picture can be found again, remade or
replaced. A file downloaded from Higgsfield has the job ID at the end of its
name, for example `hf_20261116_100217_0e36fda8-....png`.

Settings used for the finished pictures: model GPT Image 2.6, quality
"medium", size "2K". The cheap first drafts used quality "low", size "1K".
